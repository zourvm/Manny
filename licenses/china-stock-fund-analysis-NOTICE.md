# Notice

This project is adapted from concepts and workflow patterns in Anthropic's `financial-services` reference repository:

https://github.com/anthropics/financial-services

The original repository is an Anthropic financial-services plugin and managed-agent reference project. This adaptation narrows the scope to a Codex skill for China stock and mainland fund analysis, with public, non-paywalled data sources as the default.

This repository does not include or require paid institutional data connectors by default.
