# 观数 · 公开部署版

完整Streamlit看板，包含公开数据初始快照；无API凭据。

部署到Streamlit Community Cloud：将本目录放入一个专用GitHub仓库，推荐私有源码仓库；入口 `streamlit_app.py`，Python 3.12。依赖由 `requirements.txt` 安装。应用访问权限设为公开。不要复用其他项目仓库。

通用容器部署：使用本目录Dockerfile；服务监听0.0.0.0，端口使用平台PORT变量，默认8501。

公开数据快照保留真实获取日期，页面中的时效提示不表示数据今天更新。各访客在独立临时目录中刷新、导入和比较，不能改写其他访客或本地版本。云服务重启、访客会话回收后临时更新可能消失，重新载入初始快照；本版本未配置持久数据库或后台定时采集。

数据由公开行情与披露源提供，原始权利归发布方；保留来源和计算边界。地区和云出口网络可能影响AKShare、CME等来源可用性，失败保留旧数据。
