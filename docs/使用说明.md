# 观数 · 个人宏观研究台使用说明

适用版本：2026-10-30。以当前看板实际功能为准，重点说明“机构与杠杆观察”，并介绍国家队、ETF和宏观页面。

## 1. 先用五分钟熟悉看板

看板首页：http://localhost:8501 。新增资金研究页：http://localhost:8501/funds 。

1. 打开左侧“机构与杠杆观察”，选择“保险与私募”。
2. 保持“保险”，选择持仓报告期 `2026-06-30`、对比报告期 `2026-03-31`。这是当前已缓存的一组示例，后续以页面实际可选日期为准。
3. 看左图“行业持仓分布”，了解期末可见持仓集中在哪些行业；看右图“行业数量变动”，找出两期可比记录中数量增加、减少较明显的行业。
4. 打开“行业增减持明细”，核对具体账户、股票和披露状态。不要只根据柱子的颜色作判断。
5. 再切换“公募基金”，用初始样本 `000001` 查看“重大买卖”，熟悉买入、卖出两张图。此代码仅为功能样本，不是基金推荐。
6. 最后看“沪深两融”和“ETF 申赎参考”，了解公开持仓之外的近期市场参与情况。

第一次使用无需把所有接口重新采集一遍。已有成功快照可以直接查看；更换基金、年份或需要新报告期时，再点击相应采集按钮。

## 2. 选哪个页面

| 想解决的问题 | 页面 / 模块 | 可以观察的内容 |
| --- | --- | --- |
| 中央汇金、证金、社保等公开持有哪些股票 | 国家队公开持仓 | 具名账户、行业配置、两期可比股数变化、公告 |
| 某只公募在报告期间重点买过、卖过哪些股票 | 机构与杠杆观察 → 公募基金 → 重大买卖 | 已披露重大交易清单及行业汇总 |
| 某只公募期末配置在哪些行业 | 公募基金 → 持仓与行业 | 已取得持仓样本的行业市值及数量变化 |
| 保险或私募公开账户如何调配行业 | 保险与私募 | 十大流通股东中可见账户及跨期比较 |
| 融资交易参与程度近期如何变化 | 沪深两融 | 同日沪深融资余额、两融余额、观测间隔余额变化 |
| 多个宽基ETF是否同时发生份额变化 | ETF 申赎参考 | 固定基金篮子的归一份额、区间变化率 |
| ETF近期成交活跃度和行情更新时间 | ETF 交易参考 | 延迟行情、成交额、IOPV字段 |
| 外需、城市房价和经济景气如何变化 | 宏观概览 / 进出口 / 房地产 | 已接入宏观指标与统计期 |
| 某次美联储会议的利率概率分布如何变化 | 美联储预期 | 自动读取CME公开网页并保存，展示各场会议与历史预期，无需API |
| 大小盘、创业板、科创板及各行业谁更强，与杠杆是否同步 | 指数与两融对比 | 统一起点走势、同区间涨跌、原始点位与余额、变动相关 |
| 数据来自哪里、刷新是否成功 | 各模块审计区 / 数据与设置 | 来源、采集时间、质量说明和错误日志 |

这些数据有不同的统计范围。国家队是主体角色，公募/私募是产品或组织形式，量化是策略。它们可能交叉，不能将几个页面金额直接相加成“市场总资金流”。

## 3. 日期与数据时效先分清

| 日期 | 含义 | 使用时怎么读 |
| --- | --- | --- |
| 报告期 | 持仓快照或累计交易的截止日期 | 例如6月30日的持仓，不是今天的持仓 |
| 公告日期 | 该记录通过相关报告公开的时间 | 用来判断当时是否已能知道，以及披露滞后 |
| 采集时间 | 这台电脑成功读取数据的时间 | 今天采集，也可能只读到几个月前的报告 |
| 预计下次更新 | 下一期预计发布日、披露窗口或本地检查时间 | 看清“官方计划”“估计”“检查建议”，不是保证届时已有新数据 |

各数据页面的“数据时效”框统一显示数据截至 / 报告期、最近成功获取（北京时间）、预计下次更新与时效判断。国家队及保险、私募的日期跟随所选报告期；两期比较的期初数据和行业分类映射另列在展开区。

打开 **数据与设置 → 全部数据 · 获取日期与预计更新**，可同时比较所有本地数据集，并下载时效表CSV。预计日期按数据期推算；过期后保留原预计日期并显示超期天数，不自动滚到未来。历史比较期单独标注，避免将旧期对照误当成最新持仓。

- **官方计划**：PMI、房价、国房景气采用已核验的2026年统计局发布日程。
- **披露窗口**：具名股票按上市公司定报期限，公募持仓及重大买卖按对应基金报告节奏；处于窗口内不表示报告已经齐全。
- **估计 / 检查建议**：进出口、交易日数据及尚未核验的新年度日程明确标为估计。CME的15分钟是本地再次检查条件，网页源时间单列，关闭页面不会持续自动采集。
- **不定期 / 未记录**：历史ETF样本、公告选录和导入文件没有连续更新承诺；未保存成功获取时间时保留未知，原文核验日不冒充获取时刻。

时效只能帮助判断数据是否足够新，不能替代覆盖范围、准确性和原文核验。预计依据可从每个时效框的链接查看。

页面上的“报告期距今121天”，表示期末快照距今天数，不等于“晚了121天才披露”。具名股东记录有公告日期时，披露滞后按“公告日期－报告期”计算。

公募聚合接口没有提供公告日期的记录会留空，不用采集时间代替。当前公募数据因此不适合直接进行严格的历史时点回测。

## 4. 公募基金：重大买卖与期末持仓分开看

### 4.1 查看已披露重大买卖

操作路径：**机构与杠杆观察 → 公募基金 → 重大买卖**。

1. 输入六位基金代码，保留开头的0。例如初始样本是 `000001`。
2. 选择查询年份。
3. 选择“重大买卖”。没有缓存或需要更新时，点击“采集 / 更新本基金”。
4. 选择“重大买卖累计报告期”。只会出现接口实际返回的报告期。
5. 对照买入、卖出行业图，再查看下面逐只股票的金额、方向和累计期间。

**本视角的更新按钮分别采集重大买入和重大卖出，不会同时更新“持仓与行业”。** 两侧分别保存，因此可能一侧成功、一侧失败；缺失侧显示“—”或未知，不按0处理。

图表读法：

- “已披露重大买入/卖出”卡片，是该方向当前报告期清单的金额合计。
- 左右图按股票映射到行业后分别汇总，横轴均为亿元，使用相同金额刻度。
- 绿色用于买入，红色用于卖出；卖出图中的正数金额表示已卖出的成交金额，不是负持仓。
- 未匹配到行业的股票保留为“未分类”，没有从合计中悄悄删除。
- 展示的是达到披露范围的清单，不能把卡片当成该基金全部交易总额。

**累计期间尤其重要：** `2026-06-30`对应年初到半年度末，`2026-12-31`对应年初到年度末；不能把它们误读为仅第二、第四季度交易。半年与全年是部分披露名单，也不能直接相减来还原下半年完整交易。

举例：某行业在买入名单出现3亿元、在卖出名单出现2亿元。可以说“已披露清单分别列出买入3亿元、卖出2亿元”；不能据此确认该行业完整净买入1亿元，因为未上榜的买卖金额未知。

### 4.2 查看期末持仓和行业变化

保持同一个基金代码，切换“持仓与行业”，再按需点击“采集 / 更新本基金”。此时按钮更新的是基金持仓数据。

1. 选“持仓报告期”，查看这一期的行业分布。
2. 选更早的“对比报告期”，查看两期可比记录的数量变化。
3. 需要回到单期展示时，选“不比较”。
4. 在明细里核对股票代码、持有数量、持仓市值与比例分母。

当前公募页面在同一个查询年份内选择已取得的报告期，暂未提供跨年份合并对比。接口按每个报告期最多返回100条；季度重仓样本和半年度较长持仓清单的覆盖范围可能不同，不能把条数增长直接解释为扩张持仓。

不同基金份额类别可能共用同一个投资组合。本页一次查看一个基金代码，不将多个份额类别直接汇总。

## 5. 保险与私募：具名账户的行业配置

操作路径：**机构与杠杆观察 → 保险与私募**。

### 5.1 补充两个报告期

1. 选择“保险”或“私募（源分类）”。
2. 展开“采集其他报告期 / 更新账户数据”。
3. 选择一个季度末，点击“采集本报告期”。
4. 再选择另一个季度末，重新采集。
5. 收起采集区，在“持仓报告期”和“对比报告期”中选择这两期。

保险和私募分别采集、分别缓存。采集报告期决定本次请求什么数据；下面的持仓/对比报告期决定当前显示哪两期，二者不是同一个控件。

当前已有保险和私募的2026年一季度、半年度样本，可直接比较。最新报告期即使可选择，也可能仍处于披露过程中；“季度已经结束”不代表该期报告已经全部公布。账户数量下降时先核对覆盖和公告日期。

### 5.2 保险账户筛选

默认包含源站保险分类中的保险公司和保险产品。若保险公司本级的长期股权使行业分布过于集中，可以打开：

**仅看保险产品账户（排除保险公司本级）**。

该开关按源站“保险产品”账户类型筛选，不能保证剩余账户都是短期交易账户，也不能证明被排除的公司账户全部属于战略投资。

### 5.3 私募账户筛选

“私募（源分类）”沿用公开股东聚合表的私募基金分类，可能混有证券私募、股权投资产品及待进一步核验的账户关系。

- 它不是“全市场证券私募持仓”，也不是“量化资金总持仓”。
- 关注具体管理人或产品时，使用“筛选具名账户”查找披露中的完整账户名称。
- 账户分类、管理人关系和股票持仓仍需通过原报告及公开公示交叉核验。

### 5.4 哪些筛选会改变图表

| 控件 | 影响范围 |
| --- | --- |
| 持仓报告期 | 期末行业分布、指标卡和持仓明细 |
| 对比报告期 | 两期可比变化；选“不比较”则不计算跨期变化 |
| 筛选具名账户 | 同时影响图表、指标卡及相关明细；留空表示全部可见账户 |
| 仅看保险产品账户 | 先过滤保险历史持仓，再计算图表和比较 |
| 查找股票或账户 | 只筛选下方当前持仓表及其下载内容，不重新计算上方行业图 |

如果只选中一个本期未出现的历史账户，本期表可能为空。这表示当前可见样本未检出，不代表已经清仓。

## 6. 行业图、增减持和明细怎么看

### 6.1 左图：可见持仓市值

“行业持仓分布”将所选期末记录按行业汇总，单位为亿元，显示前15个行业。它回答“可见持仓集中在哪里”，不直接回答“期间买入了多少”。

股价上涨也会使期末市值变大，因此不能用两期市值差额直接判断加仓。行业标签使用当前已缓存的财报行业映射；同一映射用于回看不同报告期，并非严格的历史时点分类。

### 6.2 右图：数量变化按期初价格折算

只有同一账户、同一股票、同一披露口径在两期都出现时，才计算股数变化：

```text
数量变化 = 期末股数 − 期初股数
期初参考价格 = 期初持仓市值 ÷ 期初股数
数量变动参考额 = 数量变化 × 期初参考价格
```

例如：假设某账户从100万股增加到120万股，期初参考价格10元，则参考额为200万元。它帮助将不同股票的股数变化放到近似统一的金额尺度上，不代表实际花了200万元买入。

在当前机构页面，绿色表示参考额为正，红色表示为负，0是无净数量变化的分界。正负参考额还可能抵消，所以应同时看行业明细中的增持、减持记录数。

尚未调整送转、拆分、账户划转、换购等因素，数量变化本身也需要复核。缺少有效期初股数或市值时，不生成金额参考值。

### 6.3 三种披露状态

| 状态 | 页面怎么处理 | 不能据此认定什么 |
| --- | --- | --- |
| 两期均披露 | 计算同账户同股票的数量差额 | 仍不能直接当实际买卖或现金流 |
| 新披露（非确认新买入） | 单独列示，不把期初补成0 | 可能以前就持有，只是本期进入可见名单 |
| 本期未披露 | 单独列示，不把期末补成0 | 可能跌出前十、披露未齐或确有变化，不等于清仓 |

“记录数”按账户和股票的持仓记录计数。一个行业内多个账户持有同一只股票，记录数可能大于股票数量。

### 6.4 图表交互与下载

- 鼠标悬停柱子，查看行业及具体数值；颜色需结合正负号和单位理解。
- 图表上方工具栏可以查看数据、全屏或下载PNG；工具栏通常在鼠标移入图表时出现。
- 当前行业柱图用于悬停查看，不是点击后自动穿透到股票的交互筛选器。
- 在“行业增减持明细”展开行业汇总和账户变化，再下载CSV。
- 底部“下载所选持仓 CSV”只导出当前持仓期及当前表格筛选结果。
- 完整数据以明细和导出文件为准，不能仅凭前15行业图判断其他行业不存在持仓。
- Excel打开CSV时，将股票/基金代码列按“文本”导入，可保留开头的0。

## 7. 沪深两融：近期杠杆参与情况

操作路径：**机构与杠杆观察 → 沪深两融**。

1. 选择“两融采集起点”和“终点”。终点只能选择已结束日期，单次区间最多100个自然日。
2. 点击“增量更新两融”。已有成功历史保留，已校验的深市日期会复用。
3. 先读“合计最新日期”，再看余额曲线和变化柱图。
4. 查看“间隔自然日”与原始表，确认相邻两条观测之间隔了几天。

| 指标 | 含义 |
| --- | --- |
| 沪深融资余额 | 同一个交易日沪市融资余额＋深市融资余额 |
| 两融余额 | 融资余额与融券余额对应的合计 |
| 最近观测间隔余额变化 | 最新一条合计与上一条可见合计之间的融资余额差 |
| 沪深同日观测 | 当前缓存中可以按同日合并的观测条数 |

任何一天缺少一个交易所，就不生成该日沪深合计，不把沪市今天与深市昨天相加。周末、节假日或数据缺口会使观测间隔变长，所以柱图不能一律称作“当日净流入”。

**日期输入目前用于采集范围，不是图表显示区间。** 更新完成后，页面展示的是合并后的已有缓存历史，可能包含本次起点之前的记录。

融资余额变动不等于现金净买入；两融参与者也不只包含散户。当前未纳入北交所，未接齐同日流通市值、成交额及长历史分母，因此只展示余额，不给出杠杆热度分数。

## 8. ETF的两个入口分别做什么

### 8.1 ETF 申赎参考：看份额

操作路径：左侧 **ETF 申赎参考**。

1. 设置采集起点、终点及频率。初次使用周度采样比较容易查看较长区间。
2. 点击“增量采集 ETF 份额”。单次最多60个采样点，页面保留实际取得的交易日期。
3. 在“多宽基对比”中查看首期归一为100的份额曲线和区间变化率热力图。
4. 切到“逐宽基明细”，选择一个宽基，再查看可比基金篮子和两端变化。

当前份额模块覆盖上交所代表性宽基样本，不覆盖全部ETF及深交所。归一曲线只用于比较变化方向和幅度；110表示相对于该篮子的首期份额增加约10%，不表示流入110亿元。

各宽基在整个所选区间使用每个有效日期都存在的相同基金篮子，以降低新增或缺失基金造成的假增长。区间越长，可比篮子可能越小；没有交集时可以缩短范围。

份额热力图中蓝色为增加、红色为减少、灰色为不可比或缺失。注意它与其他页面的配色不同，按本图说明读取。周/月采样变化不是日净申购；份额变化也不能确定资金来自中央汇金、保险还是其他投资者。

### 8.2 ETF 交易参考：看行情与成交

操作路径：**机构与杠杆观察 → ETF 交易参考**。

输入用逗号分隔的沪深ETF代码，最多20只，当前接受5或15开头的六位代码，然后点击“更新 ETF 交易快照”。例如页面初始清单是 `510300,510500,510050,588000,159915`，同样只是功能观察样本。

这里显示延迟价格、IOPV字段、成交额与实际更新时间，不显示具名投资者身份。成交额说明交易活跃程度，不是资金净申购。

IOPV是基金盘中参考估值字段；本页未确认其与成交价格严格同步，不将两者直接计算为可以执行的套利信号。部分本地快照超过5分钟时，页面会提示查看更新时间；这是快照，不会自动实时刷新。

修改代码输入框不会立刻改变已缓存的图表。点击更新并成功取得新清单后，才会显示新结果。

## 9. 国家队与宏观页面

### 国家队公开持仓

先选中央汇金、证金、国新、诚通、社保、养老金等主体，再选择观察方式：

- **行业观察**：选期初/期末，查看行业分布、期初价折算参考额或增减持记录数；在“查看行业”下拉框中进一步检查行业内股票。
- **持仓对比**：看同一期各主体可见市值及持仓交集；ETF只比较同一只基金的具名持有份额。
- **两期变动**：核对账户和股票的数量变化，区分新披露、未披露与两期可比记录。
- **公开公告**：看已选录事件和来源，不将不同口径公告金额直接加总。
- **数据与方法**：采集所选股票报告期，或按模板导入有明确来源的具名披露。

“隐藏中央汇金投资本体账户”只排除完整名称为中央汇金投资有限责任公司的记录，汇金资管等其他账户仍保留。它是观察筛选，不是对每笔持仓投资目的的认定。

国家队ETF具名持仓目前是有原文支持的历史样本，不等于最新完整持有人名单；缺少新名单时不能推断卖出。行业图也不会自动穿透ETF底层股票。

### 宏观概览、进出口、房地产

- 宏观概览用于快速查看已接入指标及各自最新统计期。不同指标可能更新到不同月份。
- 进出口“总量与增速”可切换当月、年初累计，金额与同比要分别读；行业/商品结构目前使用CSV导入，按页面模板预览后保存。
- 房地产可切换城市房价、行业景气；房价可区分新房/二手房、同比/环比。当前没有接入销售、投资、开工、竣工全套数据。
- 侧栏时间范围影响使用该筛选的宏观、ETF历史图；指标卡仍显示最新有效观测。
- 国家队与机构持仓按页面自己的报告期选择；机构与杠杆页目前也不跟随全局侧栏截取图表。

### 美联储预期

默认自动读取CME公开网页并填入面板，不需要手工抄数、API、订阅或密钥：

1. 打开“美联储预期”，默认开启“打开页面时自动读取公开数据”。页面打开或重新运行时检查更新，15分钟内最多自动请求一次。
2. 点击“立即自动读取并填入”可不等缓存时间，马上重新读取。工具按公开会议标签逐场切换，读取全部会议和有实际日期的历史比较列。
3. 先看“各场会议 · 降息 / 维持 / 加息预期”，再选择具体FOMC会议和报告日，查看目标利率区间分布与历史曲线。
4. 比较基准来自网页标注的Current利率，自动填写；历史比较列没有提供当时基准时不会猜测或自动补填。
5. 检查“网页数据日”和“来源时间（原文）”。网页原始日期不改成本地采集日期；部分远期会议没有1天/1周/1月前数据时保持缺失。
6. 读取失败保留已有成功数据；页面给出提示，采集日志也会记录错误。关闭页面后不会在后台持续采集，没有额外定时任务。

自动汇总优先保留网页的降息、维持、加息百分比，并校验它们与利率区间明细加总相符。由于网页各值独立舍入，两种口径可能有微小差异；不会强制改为100%。自动读取来源与校验区保留逐会议时间、缺失列和公开表格指纹。

下列手工方式仅在“备用：手动录入 / 文件导入”展开使用：

1. 点击“打开 CME FedWatch 公开网页”，在工具中选择会议日期，查看Current里的目标利率区间与概率。
2. 回到看板，展开“录入网页概率 / 导入表格”，选择“网页对照录入”。
3. 填会议日期、网页报告/观测日期。页面显示的更新时间及时区按原文保留；未显示时留空，不能用本地录入时间冒充。
4. 逐行填写利率下限、上限及概率，可增加行，也可从表格粘贴。325–350基点应填3.25、3.50；68.5%应填68.5，不能填0.685。
5. 所有区间都录完后检查合计，点击“核对后保存概率快照”。概率合计允许最多0.2个百分点舍入误差，不会强制改为100%。未知区间不能填0。
6. 同一会议每天记录一份，可积累历史预期曲线。同一会议同一报告日再次保存会替换当天整份分布，其他日期保留；当前没有把同一天多次记录单独绘成日内曲线。

批量录入时选择“导入 CSV / Excel”，下载空白模板，填写 `会议日期,报告日期,利率下限（%）,利率上限（%）,概率（%）`，可选附加“来源时间（原文）”。可以一次导入多个会议或报告日。CME工具下载文件若采用其他表头，需要先转换为模板。旧的CME原始JSON仍可在“兼容原始 JSON”导入；该格式利率为基点、概率为0–1，与网页录入单位不同。

自动读取沿[CME官方中文FedWatch页面](https://www.cmegroup.cn/fed-watch/)的公开嵌入工具和正常会议表单导航完成，不使用付费接口或第三方转录概率。网页概率来自期货市场定价推算，不是美联储官方承诺；功能介绍见[官方使用指南](https://www.cmegroup.com/tools-information/quikstrike/cme-fedwatch-tool-user-guide.html)。

有数据后先选FOMC会议，再选概率报告日。比较同一场会议在不同报告日的分布变化，避免把不同会议混为一谈。“相对基准”需自行填写并核实当前目标利率下限；相对该基准的宽松概率不等于相对上一场会议的单次降息概率。

## 10. 更新、核验与故障处理

### 指数与两融对比怎么用

打开左侧 **指数与两融对比**，或从“机构与杠杆观察”顶部链接进入。

1. 选择“主要板块”“大小盘”“行业对比”组合，或分别搜索宽基与行业名称、代码，自选多条指数。
2. 选择近3月、近6月、近1年等独立区间，或自定义起止日期。该页不使用侧栏图表时间筛选。
3. 选择两融余额、融资余额或融券余额，开启叠加。系统只取所有已选有效指数与两融的共同日期，统一第一个共同日为100，不填补缺失日期。若新指数历史短，共同起点会变晚；实际共同起止和观测数会直接显示。
4. 先看统一起点图，比较涨幅与余额变化；点击图例突出曲线。再看“区间强弱”的涨跌排名、区间最大回撤。
5. 在“点位与余额”选择重点指数，上图看原始指数点位，下图看市场余额（亿元）。上下纵轴独立，不能仅凭斜率判断谁变化更大。
6. “变动相关”使用相邻共同观测的指数涨跌和余额百分比变化，至少20对才计算Pearson系数；缺口对应区间变动，不一定是日收益。相关不说明资金归属、因果、领先性或预测能力。
7. 底部“数据时效”可看重点指数和两融的最近获取、截至日、预计更新；展开查看所有所选指数。下载区提供共同日期原值、统一起点数据和区间比较CSV。

初始观察目录含沪深主要指数、创业板、科创50/科创综指、中证500/1000/2000、A500等，以及中证全指行业、银行、证券等行业指数。行业口径与持仓页财报行业不同。上证、深证、宽基和行业成分可能交叉，不相加成市场总量。

**两融范围：** 只合并同日沪市和深市历史，排除北交所；不是各指数成分股或行业各自的两融余额。源站默认“全部市场”包含北交所，因此采集时分市场过滤。最新可用日与交易所同日汇总交叉核对，深市亿元、沪市元分别换算；单日抽查不代表全历史已逐日复核。交易所页面金额舍入可能造成小差异。

**指数口径：** 收盘价格指数，不含分红再投资；部分历史可能包含指数发布前回溯值，不能视为当时可投资业绩。当前目录不覆盖所有指数。来源失败保留旧快照，明确标注备用来源与实际历史覆盖；未采集指数不生成演示曲线。

需要更新时展开“采集 / 更新历史数据”，选采集区间，点击“更新所选指数与两融”。只采集已结束日期，按指数分别保存；缩短采集区间会替换当前可见快照，更早成功版本仍保留在本机。首次宽范围采集可能需要几分钟。

### 更新后检查四件事

1. 实际报告期或观测日期是否符合预期。
2. 两期比较的账户、披露口径、行业映射和覆盖范围是否一致。
3. “来源、披露滞后与数据审计”中是否有缺失、回退或未核验说明。
4. 重要股票和账户是否能从原始报告得到支持。

“公开来源 / 核验入口”可能打开聚合页面或报告检索入口，不一定直达原始PDF。“聚合数据·待原文复核”与“原文已核验”应区别对待；当前抽查过的个别记录不能代表全表核验完成。

目前美联储页面会在打开或操作页面时自动检查网页更新（15分钟限频），也有立即重读按钮；其他模块由各自的按钮手动更新。没有关闭页面后持续运行的定时采集、消息提醒或交易操作；一个页面的刷新不会自动更新所有页面。

### 常见情况

| 页面现象 | 原因或下一步 |
| --- | --- |
| 选择基金后没有数据 | 该代码/年份/视角尚无成功缓存，或源站未提供；点击相应采集按钮，查看结果 |
| 买入有数据，卖出为“—” | 两侧独立请求，可能一侧未披露或失败；不要将缺失侧当成0 |
| 无法选择两期对比 | 当前只有一期可用；先为同一类别补采更早报告期 |
| 行业图显示“未分类” | 保留了未匹配股票；可到国家队“行业观察”底部更新行业分类，海外代码仍可能无法匹配 |
| 选一个历史账户后本期为空 | 当前样本没有该账户本期记录；可取消账户筛选或切换报告期，并核对原报告 |
| 切换报告期后行业规模骤变 | 先检查新旧清单披露范围、覆盖数量、长期本级账户及分类，不直接认定集中加减仓 |
| 两融日期少于工作日数 | 可能是休市、某一市场尚未返回或接口缺失；合计只保留同日两市均可用的记录 |
| 刷新失败但图还在 | 正在显示上次成功快照；到“数据与设置 → 采集日志”查看原因，稍后再试 |
| 显示“更新成功”，统计期仍旧 | 接口请求成功不代表源站已发布新数据；按实际报告期判断 |
| localhost拒绝连接 | 本机Streamlit服务没有运行；双击项目中的“启动看板.cmd”，再打开页面 |
| 重新启动却看到旧版本 | 可能8501端口已有旧服务；关闭本看板原服务后重新启动，避免同时运行多个实例 |

### 启动与备份

在本机双击项目目录中的 **启动看板.cmd**，浏览器访问 http://localhost:8501 。关闭网页标签不会停止后台服务。通过启动脚本在终端运行时，可以在对应终端按Ctrl+C停止。

当前项目目录为 `项目部署目录`。成功快照保存在该项目的 `data/snapshots.sqlite3`。备份或迁移前先停止服务，再复制项目和数据文件，避免遗漏SQLite尚未合并的WAL内容。

当前依赖还使用工作区 `work/python-packages`；迁移到另一台电脑时不能只复制网页代码就假定依赖已经齐全，具体环境安装见项目README。

## 11. 一次完整观察可以这样记录

每次只围绕一个明确问题，例如“在两期公开披露的可比账户中，哪些行业的持股数量变化比较突出”。

1. 固定主体/账户、期初、期末及披露口径，记下更新时间和覆盖数量。
2. 先看期末行业分布，再看数量变化参考额，最后读具体股票和账户明细。
3. 将新披露、未披露和两期可比记录分别记录，避免覆盖变化混进调仓结论。
4. 对重要记录打开来源入口复核，检查送转、拆分、账户划转及报告期间。
5. 如需观察更近期的市场参与，可另看ETF份额和同日两融，但保留各自日期和身份未知的边界。
6. 导出CSV和研究口径JSON，记录“看到了什么、算出了什么、还不能确认什么”。

一条合适的研究记录是：“在所选两期、所选账户的可见样本里，该行业可比股数增加；参考额按期初价折算。新披露账户另列，尚未确认实际成交日期和买卖金额。”这比直接写“某类资金今天净流入多少”更符合本看板目前的数据能力。
